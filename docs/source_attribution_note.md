# Source Attribution Note

This dashboard is a public-facing, source-linked plant guide. It summarizes structured plant traits and points users back to source pages for full context.

## NPSOT

Propagation source data were provided directly to Calvin King / City of Kyle by NPSOT in September 2025 for native plant and propagation work. The public dashboard displays summarized propagation materials, treatment tags, source URLs, and reference URLs rather than full protocol text.

Before formal launch, confirm NPSOT's preferred public attribution wording.

## Wildflower Center

Plant profile links point to the Lady Bird Johnson Wildflower Center Native Plants Database where available. The public dashboard does not redistribute Wildflower Center image URLs, long prose fields, or page boilerplate.

## Photos

Plant photos are loaded dynamically from iNaturalist and Wikimedia Commons only when reusable license information is available. Source database photos are not bundled in this repository.
