# Public Data Boundary

This repository is the public-facing dashboard build.

## Public files include

- plant names and compact trait categories
- habitat and microregion tags
- propagation material/treatment tags
- short propagation note saying full protocols are linked but not reproduced
- source URLs and attribution notes

## Public files intentionally exclude

- full NPSOT propagation paragraphs
- NPSOT collection/protocol paragraphs
- Wildflower Center long prose fields
- source database photos and image URLs
- page boilerplate, scrape/debug fields, and raw source tables
- internal or unpublished source files

## Information retention

Full source files should be retained only in a private/internal archive outside the public GitHub repository.
