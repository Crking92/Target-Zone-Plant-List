# Public Release Checklist

## Required before public launch

- [ ] Confirm preferred NPSOT attribution wording.
- [ ] Keep original NPSOT permission email and attachments in internal records.
- [ ] Keep raw source files out of the public repository.
- [ ] Verify `data/raw/` is not committed.
- [ ] Confirm no full source prose or full propagation protocols are in `data/processed/`.
- [ ] Spot-check several plant cards against source links.
- [ ] Decide whether to create a fresh public GitHub repository if old raw files were already committed.

## Good next upgrades

- [ ] Add BONAP/NAPA target-zone status per species.
- [ ] Add a visible attribution block with NPSOT-approved wording.
- [ ] Add a version/date tag to the webpage footer.
- [ ] Add a simple issue-report link for public corrections.
