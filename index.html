Plant_ID is the Scientific Name. Microregion fields are merged into each plant record by Scientific Name so plant searches stay one row per plant.

Public data policy: this dashboard displays structured plant traits, short source-attributed summaries, and links back to source pages. Long source prose, source database photos, image URLs, page boilerplate, and full propagation protocols are intentionally excluded from the browser-delivered data files.

Plant profile links point to the Lady Bird Johnson Wildflower Center Native Plants Database where available. Hays County microregion fields are displayed separately when available.

Plant photos, when available, are loaded first from iNaturalist observations with reusable Creative Commons photo licenses. If no suitable iNaturalist photo is found, the dashboard tries Wikimedia Commons. Photo creator, source link, and license are displayed with each image.

Propagation fields are summarized from Native Plant Society of Texas data and linked source pages. This public dashboard shows materials, treatment tags, source URLs, and reference URLs rather than republishing full source protocols.
